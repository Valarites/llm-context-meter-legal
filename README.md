# llm-context-meter-legal
Public legal and support documents for LLM Context &amp; Usage Meter, a browser extension for monitoring AI conversation context usage.

# LLM Context & Usage Meter — Legal and Support

This repository contains the public privacy policy, terms of service,
refund policy, support information, and third-party notices for
LLM Context & Usage Meter.

The extension processes supported conversation content locally in the
browser to estimate context usage. It does not upload raw conversation
text to the developer's servers.

These documents apply to the currently published version of the extension
and may be updated when the product or applicable requirements change.
